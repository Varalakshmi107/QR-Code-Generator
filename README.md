# QR-Code-Generator
A simple and user-friendly QR Code Generator built using HTML, CSS, and JavaScript.

## Features
- Generate QR codes from text or URLs.
- Simple and clean user interface.
- Input validation.
- Fast QR code generation.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- QR Server API

## How to Use
- Enter any text or URL.
- Click on the Generate QR Code button.
- Your QR Code will be displayed.

## Project Preview
QR Code Generator generates QR codes for the entered text or URL.
